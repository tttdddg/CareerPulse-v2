# CareerPulse 前端离线录屏配置

## 启动

```powershell
cd D:\vue\CareerPulse-Pro\front
npm run dev:demo
```

浏览器打开：`http://localhost:5173/#/app/input`

## 推荐录屏流程

1. 在“数据输入中心”上传任意 PDF 或 Word 简历；前端会稳定返回同一份 AI Agent 开发候选人数据。
2. 上传完成后直接点击“开始分析”；结构化结果已自动回填到表单，不单独展示解析表格。
3. 在“岗位匹配”展示 82% 匹配度、能力雷达、优势和六项能力差距。
4. 打开“岗位”，AI 职业伙伴会自动展开；可点击四个快捷问题或自行输入问题，展示岗位推荐、30天计划、项目优化与面试建议。
5. 打开“职业路径”，展示 25 个总图节点，以及 3 级晋升、10 个换岗方向和岗位详情。
6. 打开“成长计划”，展示六项学习任务、四项学习资源和四个相关岗位机会。
7. 打开“职场训练”，在已加载的 AI 办公任务中自行输入任意非空回答并提交；前端稳定返回 88.8 分及完整维度反馈。
8. 打开“成长档案”，展示学习记录、训练记录、反馈记录和成长趋势。

## 数据与边界

- 页面身份和组织名称均为虚构，未保存真实姓名、联系方式、学校、公司或私人链接。
- 上传文件只用于触发前端交互，案例分支不会读取并保存简历正文。
- 匹配、AI 职业伙伴、图谱、计划和训练反馈均由浏览器回放预设数据，不请求后端、数据库、外部模型 API 或 Ant TBox。
- 录屏页面不显示离线配置标识，PDF/Word 导出入口在该配置下保持隐藏。
- 默认 `npm run dev` / `npm run build` 仍使用真实 API 模式。

## 主要代码

- `src/demo/careerDemoData.ts`：学生、岗位、匹配、图谱、资源、报告与历史数据。
- `src/demo/demoRequest.ts`：本地异步请求适配器。
- `src/demo/trainingDemo.ts`：训练任务和固定反馈。
- `src/demo/assistantDemo.ts`：AI 职业伙伴快捷问题与固定回答。
- `src/demo/demoMode.ts`：环境开关和本地异步延迟。
- `.env.demo`：启用 `VITE_DEMO_MODE=true`。
