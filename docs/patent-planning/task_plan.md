# CareerPulse 第一件发明专利成文计划

## 目标

以“优化的 DPO 模型”为第一件发明，依据用户亮点笔记与 CareerPulse 代码仓库，完成证据约束的技术交底书及中国发明专利申请四件套；缺少的技术事实单列为待确认问题，不在正式权利要求中虚构。

## 阶段

- [completed] 阶段 1：读取亮点笔记、代码证据与两套 Skill 的必读规则，建立案卷和证据账本
- [completed] 阶段 2：完成轻量现有技术检索、D1 对比和发明点门禁
- [completed] 阶段 3：生成技术交底书、结构化证据台账和附图并通过门禁
- [completed] 阶段 4：生成权利要求书、说明书、摘要和附图 DOCX
- [completed] 阶段 5：执行支持性、引用关系、公式、格式、逐页渲染和项目测试，整理待确认问题

## 约束

- 不虚构算法、实验结果、性能指标或技术效果。
- 不读取或输出真实简历、用户身份信息、令牌和密钥。
- 不把纯职业推荐规则包装成技术方案。
- 正式提交前需由中国专利代理师复核。
- “优化的 DPO”若只有方案设想而没有已实现证据，可写入交底书的拟实施部分，但不得伪装为已经验证的实验结论；正式权利要求只纳入能够被材料支持并可实施的技术特征。

## 安装决策

- 本轮不执行安装。
- 三个候选仓库根目录均含 `SKILL.md`，可由系统 `skill-installer` 使用 `--path . --name <skill-name>` 安装完整仓库。
- 推荐先安装到个人技能目录做受控试验，不把第三方仓库直接提交进 CareerPulse；若后续需要团队共享，再审计后复制到项目 `.agents/skills`。
- 第一阶段只启用 `patent-disclosure-skill` 和 `paper-to-cn-patent`；`patent-writer` 先作为 QC 参考，避免三个大流程同时触发。

## 候选发明边界

### 候选一：受多源可信度和确定性约束的自适应 DPO 对齐方法

- 不把“职业推荐规则”本身作为发明核心。
- 聚焦偏好样本构造、无效样本门禁、样本级自适应权重/温度、训练与推理一致性校验。
- 现阶段是拟研发方案，必须补训练实现和实验后再进入正式撰写。

### 候选二：面向职业导航多智能体的时序证据记忆管理方法

- 不申请公开 Memobase 本体，也不以品牌名作为发明核心。
- 聚焦带来源/时间/置信度/隐私级别的职业证据记忆、冲突消解、角色分域投影、确定性结果隔离和最小上下文装配。
- 可复用当前画像、状态、历史、反馈和日志作为起点，但仍需实现统一记忆流水线和量化评测。
