# CareerPulse 前端演示模式任务计划

## 目标

在不依赖后端、数据库或外部模型 API 的情况下，将已确认的匿名简历案例接入现有 Vue 前端，形成可重复录屏的 Demo Mode；保留现有真实 API 路径，关闭演示开关后行为不变。

## 约束

- 不修改后端或公共 API 字段。
- 不写入真实姓名、手机号、邮箱、学校、公司或私人链接。
- 演示分数、雷达、差距和成长趋势必须使用已确认的同一组数据。
- 演示状态集中管理，不在多个页面散落硬编码。
- 不覆盖工作树中任务开始前已有的未提交改动。

## 阶段

1. **complete** — 审计前端 API、Store、路由和各页面的数据依赖，冻结最小接入边界。
2. **complete** — 建立类型安全的 Demo 数据源、环境开关和异步 API 适配层。
3. **complete** — 接入数据输入、匹配、路径、成长计划、训练与成长档案流程。
4. **complete** — 增加清晰的演示标识和便捷入口，优化录屏状态恢复。
5. **complete** — 运行类型检查、构建和必要测试，复核差异与隐私。

## 已冻结决策

- 主目标岗位固定为 ID 149 的“AI Agent 应用开发工程师（校招）”，匹配分 81.67。
