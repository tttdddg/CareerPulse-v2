## 2. 必须依赖的百宝箱能力（REQUIRED）

| # | 能力 | 用途 | 无此能力的备选方案 | 验证方法 |
|---|------|------|-------------------|---------|
| 1 | **智能体创建** | 创建 "CareerPulse 职业成长伙伴" | 无备选——这是必做平台 | D1 创建并截图 |
| 2 | **模型配置** | 选择对话大模型（推荐千问/Qwen系列） | 无备选 | D1 查看可用模型列表 |
| 3 | **系统 Prompt 配置** | 写入角色、行为约束、工具调用规则 | 无备选 | D2 配置并测试 |
| 4 | **知识库创建与检索** | 上传岗位趋势/行业报告，供智能体检索 | 无备选——A02 要求知识库 | D3 创建并测试 10 个检索问题 |
| 5 | **工具调用（MCP 或 HTTP API）** | 调用 7 个 CareerPulse 业务工具 | 若平台不支持 MCP，用 HTTP API 代替 | D2 配置 1 个 Mock 工具测试 |
| 6 | **Web 发布** | 生成独立 Web 聊天页面 | 无备选——A02 要求多端发布 | D8 发布并截图 |
| 7 | **对话记录查看** | 调试和截图材料 | 无备选 | 每次测试后查看 |

## 5. D1 必须验证的关键问题

> 以下问题必须在 D1 通过实际操作百宝箱获得答案。

| # | 问题 | 对架构的影响 | 验证结果 | 验证日期 |
|---|------|------------|---------|---------|
| 1 | 平台支持 MCP 协议还是 HTTP API 工具？ | 决定 `backend/app/mcp/` vs `platform/tbox_adapter.py` 实现方式 | **待填写** | D1 |
| 2 | 可用模型列表（模型名、上下文长度、是否支持 function calling） | 决定系统 Prompt 长度和 LLM 调用策略 | **待填写** | D1 |
| 3 | 知识库支持的文件格式和大小限制 | 决定数据预处理脚本的输出格式 | **待填写** | D1 |
| 4 | 工具调用的超时限制 | 决定后端接口 timeout 设置 | **待填写** | D1 |
| 5 | 工具返回结果的大小限制 | 决定输出数据是否需要分页或压缩 | **待填写** | D1 |
| 6 | 是否有 API 调用频率/并发限制 | 决定评测时的并发策略 | **待填写** | D1 |
| 7 | Web 发布是否需要审核 | 决定 D8 发布的时间余量 | **待填写** | D1 |
| 8 | 小程序发布是否需要企业资质 | 决定是否走"预览模式" | **待填写** | D1 |
| 9 | 知识库条目数量限制 | 决定知识库拆分粒度 | **待填写** | D1 |
| 10 | 系统 Prompt 字符数限制 | 决定 Prompt 精简策略 | **待填写** | D1 |
