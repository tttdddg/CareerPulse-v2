# CareerPulse: AI职业导航与成长规划系统

​	基于 Vue 3、FastAPI 与 AI Agent 的职业发展辅助系统，面向高校学生及青年求职者，提供从能力分析、岗位匹配到路径规划、模拟训练与成长反馈的一体化服务。

​	CareerPulse 是一个前后端分离的自研 Web 项目。项目围绕“**诊断 → 规划 → 训练 → 反馈**”的业务流程，将学生画像、岗位能力要求与职业成长任务连接起来，帮助用户理解自身能力结构、识别目标岗位差距，并逐步调整成长计划。

​	项目不仅关注大模型生成的文本建议，也重视**结构化业务结果、可视化交互、服务分层、数据持久化和可重复验证**。

> **当前状态**：核心页面和部分业务服务已实现，项目正进行部署、前后端联调与稳定性完善。Demo/Mock 模式可用于演示与测试；正式用户认证、真实模型链路及部分业务数据仍需按实际配置进一步验证。

## 核心功能

| 模块 | 功能描述 |
| --- | --- |
| 用户信息与简历 | 录入个人信息、教育与技能背景，为职业分析提供基础数据 |
| 职业能力画像 | 对用户能力、经历与发展方向进行结构化分析与可视化展示 |
| 岗位分析与人岗匹配 | 分析目标岗位的能力要求，计算匹配情况并识别能力缺口 |
| 职业路径规划 | 围绕目标岗位组织阶段性发展路径及成长任务 |
| 学习与岗位资源 | 根据职业目标和能力差距提供资源推荐与参考信息 |
| 模拟训练与评分 | 围绕职业技能设计练习任务，提供评分及改进反馈 |
| 成长档案与反馈 | 汇总训练、阶段反馈与历史记录，支持后续复盘 |

上述功能的**页面呈现、Demo 行为与真实模型/数据驱动的可用程度可能不同**，应以当前分支实际联调结果为准。

## 自研系统架构

```text
                   CareerPulse Web
                 Vue 3 + TypeScript
                          │
                 路由 / 状态管理
                          │ HTTP API
                          ▼
                  FastAPI Backend
                          │
             ┌────────────┴────────────┐
             │                         │
      业务 API / Schema           Agent / 编排逻辑
             │                         │
             └────────────┬────────────┘
                          ▼
                    业务 Service 层
          ┌───────────────┼────────────────┐
          │               │                │
       职业画像       岗位匹配与规划     训练与成长反馈
          │               │                │
          └───────────────┼────────────────┘
                          ▼
                    数据与状态持久化
                 PostgreSQL / SQLite

       AI 相关服务可按配置调用模型 API 或 Mock
```

- **前端层**：负责数据采集、结果展示、交互流程与客户端状态管理。
- **接口层**：由 FastAPI 提供统一 HTTP 接口及请求参数校验。
- **Agent/业务层**：将职业画像、岗位分析、匹配计算、路径推荐、训练和成长反馈拆分为相对独立的处理单元。
- **数据层**：存储业务数据和必要的运行状态，便于后续复用和追踪。

这种设计使业务计算不必完全依赖大模型输出，便于测试、调试和后续替换模型供应商。

## 核心业务流程

```text
用户信息 / 简历
       ↓
职业能力画像
       ↓
目标岗位分析
       ↓
人岗匹配与能力差距识别
       ↓
个性化职业路径规划
       ↓
学习资源 / 成长任务
       ↓
模拟训练与反馈评分
       ↓
成长档案更新
       └────────→ 后续评估与路径调整
```

## 工程实现特点

**前后端解耦**：采用 Vue 3 + FastAPI 分离式架构，页面和后端服务可分别开发、构建及部署。

**结构化职业分析**：将用户信息、岗位要求、匹配结果和成长任务组织为可由页面消费的数据结构，而非仅返回自由文本。

**模块化业务服务**：围绕画像、岗位、匹配、路径、训练和反馈划分职责，方便单模块调试与集成测试。

**可控的 Demo/Mock 模式**：在外部模型能力尚未完整配置时，用确定性演示数据检查前端页面和部分接口行为；Mock 输出不能替代真实 AI 效果评测。

**部署和状态管理**：支持通过服务器环境变量设置运行参数，并将需要持久化的状态存放在独立于代码发布目录的位置。

## 本地运行

### 1. 环境要求

- Node.js 与 npm（版本以 `frontend/package.json` 及锁文件为准）
- Python（版本以当前后端依赖声明为准）
- PostgreSQL（在使用相关持久化业务能力时）
- 项目所需的环境变量与依赖服务

### 2. 启动前端

```bash
cd frontend
npm install
npm run dev
```

浏览器访问 Vite 在终端打印的本地地址。构建前端：

```bash
npm run build
```

### 3. 启动后端

下列命令适用于后端依赖文件为 `requirements.txt`、FastAPI 应用入口为 `app.main:app` 的目录布局；使用前请与当前仓库核对。

```bash
cd backend
python -m venv .venv

# Linux / macOS
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1

pip install -r requirements.txt
uvicorn app.main:app --reload
```

如项目启用了 Swagger UI，可通过本地 `/docs` 查看接口文档。

### 4. Demo/Mock 环境配置

以下仅示意此前项目使用过的主要开关，具体变量及默认值以当前分支环境模板为准：

```dotenv
A02_DEMO_MODE=true
A02_LLM_MOCK_MODE=true
A02_LLM_API_KEY=
A02_LLM_BASE_URL=https://api.openai.com/v1
A02_STATE_DB_PATH=/absolute/path/to/state.db
```

Demo/Mock 适合初次联调和演示，**不代表真实模型调用成功**。开启真实模型前应检查 API Key、模型名称、Prompt 资源、网络连接和相关测试。

不要提交 `.env`、生产环境变量文件、用户隐私数据、数据库凭据或其他密钥。

## 部署思路

前端执行生产构建后部署为静态 Web 资源；后端在 Linux 环境运行 FastAPI 服务，可由 systemd 管理进程，并通过服务端环境文件注入配置。数据库和持久化状态应独立于代码发布目录。实际反向代理、HTTPS、服务名称与启动参数应以部署脚本为准。
