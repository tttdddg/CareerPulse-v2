# 本地 Vue 具体怎么接百宝箱

这里不要让 Vue 浏览器直接拿百宝箱 Token。

官方示例虽然展示了 Node SDK 使用 `authorization` 调用百宝箱，但 Token 属于服务端凭据。

所以推荐这样。

你现有：

```
frontend/
└── Vue3

backend/
└── FastAPI
```

在 FastAPI 再增加一个百宝箱适配层：

```
backend/app/platform/tbox/
├── client.py
├── chat_service.py
└── schemas.py
```

再提供一个给 Vue 用的接口：

```
POST /api/tbox/chat
```

Vue 发送：

```
{
  "message": "我是计算机专业学生，想做AI应用开发",
  "session_id": "xxx"
}
```

FastAPI 再请求百宝箱：

```
TBOX_APP_ID
TBOX_TOKEN
userId
query
```

百宝箱官方公开示例也是围绕：

```
appId
query
userId
```

调用智能体并接收流式结果。



#### 然后 Vue 页面完全可以保持自己的特色

例如你已经做的页面不用扔：

```
CareerPulse

首页
│
├─ AI职业伙伴
│   ├─ 左侧对话
│   └─ 右侧动态分析结果
│
├─ 我的职业画像
│   └─ 雷达图
│
├─ 人岗匹配
│   ├─ 匹配度
│   └─ 能力Gap
│
├─ 职业路径
│   └─ 3-5年路径图
│
├─ 学习计划
│
├─ 模拟训练
│
└─ 成长档案
```

尤其可以做一个很有特色的组合界面：

```
┌──────────────────────────────────────────┐
│ CareerPulse                              │
├───────────────┬──────────────────────────┤
│               │                          │
│ AI职业伙伴     │   我的职业画像             │
│               │                          │
│ 用户：         │        Python ●────      │
│ 我想做AI开发   │       /         \        │
│               │      ●   雷达图    ●      │
│ AI：           │       \         /        │
│ 正在分析你的   │        ●───────●         │
│ 岗位匹配情况…  │                          │
│               │   匹配度 78%              │
```

> 百宝箱负责对话。

> CareerPulse 自研前端负责数据可视化。

这个展示效果会比一个纯聊天机器人强很多。
