## 1. UI 继承策略

本轮严格继承了现有 CareerPulse：

- 布局：原 240px Sidebar、74px Header 和内容区结构。
- 卡片：16px 面板圆角、12px 内容卡片、浅色边框。
- Spacing：页面 16–18px 间距及现有 Grid 换行习惯。
- 色彩：原靛青主色、灰白背景和正文层级。
- 字体：Noto Sans SC / Manrope。
- 图表：继续复用现有 `GrowthChart` 及 resize 机制。
- Button / Tag：继续使用 Element Plus primary、plain、text 和现有 Tag 样式。
- Empty / Loading / Error：使用 `el-empty`、`v-loading`、`el-alert`。

未修改全局主题色、Header、Sidebar 结构、字体系统或全站卡片规范。

## 2. 页面改动

### 学习计划 / 资源推荐

原页面只有成长报告编辑器和简化学习建议。

现在增加了：

- 当前目标岗位、主要 Skill Gap、学习阶段、完成任务数概览。
- 基于真实 `gap/gapDetails` 的结构化学习任务。
- 结构化学习资源卡片。
- 岗位资源正式 empty 状态。
- 显式报告生成入口。

保留了：

- 报告正文查看与编辑。
- 智能润色。
- 内容检查 unavailable 提示。
- PDF/Word 导出。

真实接口：

- `GET /recommendations`
- `POST /reports/generate`
- `GET /reports/{id}`
- `POST /reports/{id}/polish`
- `GET /reports/{id}/export`

接口未返回的阶段、进度、投入、推荐理由、来源等字段统一显示“暂无/未提供”。

### 职场训练

新增路由：`/app/training`。

页面包含：

- 三种训练类型卡片。
- 场景、角色、任务和回答区域。
- 未开始、生成中、待回答、评分中、评分完成、错误、unavailable 状态。
- 总分、维度评分、优点、改进项、下一步建议的正式结果结构。

仅展示后端真实支持的：

- 远程协作
- AI 办公任务
- 跨角色沟通

当前 Vue 没有训练生成、评分 HTTP API，因此实际操作明确显示“训练服务接入中”，不会产生假任务或固定评分。

### 成长档案

在原 `Profile.vue` 基础上完成，没有推翻历史能力。

复用了：

- 用户信息区域。
- `GrowthChart`。
- 历史分析列表。
- `/users/{userId}/histories`
- `/histories/{id}/snapshot`
- 历史详情 Dialog。

新增：

- 目标岗位、最近匹配分、分析次数、最近记录时间概览。
- 明确命名的“历史匹配分变化”。
- 学习记录、训练记录、成长反馈区域。

概览和曲线仅来自当前真实分析上下文或服务端历史。学习、训练、Feedback 尚无查询接口，因此均为 empty/unavailable。
