## 1. 当前真实接口契约

前端响应拦截器会自动解包后端 `{ code, msg, data }`，页面和适配器直接接收 `data`。

| 能力         | 真实接口                               | 本轮确认的关键契约                                           |
| ------------ | -------------------------------------- | ------------------------------------------------------------ |
| 简历上传     | `POST /student/upload/resume`          | multipart `file`；返回 `student_id`、`student_name`、`profile` |
| 手工画像     | `POST /student/upload/profile`         | 接收 `name`、`skills`、`certificates`、`internships`、`self_evaluation` |
| 学生画像查询 | `GET /student/{student_id}/profile`    | 返回持久化画像；当前前端尚未单独调用                         |
| 岗位查询     | `GET /jobs`                            | 参数 `keyword/page/size`；返回 `{ total, jobs }`             |
| 岗位画像     | `GET /jobs/{job_id}/profile`           | 返回真实岗位画像                                             |
| 岗位图谱     | `GET /jobs/{job_id}/graph`             | 返回 `center/vertical/lateral/relations`                     |
| 人岗匹配     | `POST /matching/analyze`               | 返回 `overall_score`、`dimensions`、`gap_analysis`、`history_id` |
| 生成报告     | `POST /reports/generate`               | 返回 `report_id/status`，不直接返回完整正文                  |
| 报告详情     | `GET /reports/{report_id}`             | 返回报告 `content/status/created_at`                         |
| 报告润色     | `POST /reports/{report_id}/polish`     | 返回 `polished_text`                                         |
| 报告导出     | `GET /reports/{report_id}/export`      | `format=pdf/docx/txt`                                        |
| 历史列表     | `GET /users/{user_id}/histories`       | 返回历史数组，包含 `history_id/job_title/created_at/match_score` |
| 历史快照     | `GET /histories/{history_id}/snapshot` | 返回分析、画像、岗位、报告正文等快照                         |
| 学习推荐     | `GET /recommendations`                 | 参数 `gap`，返回资源推荐列表                                 |

已确认不存在并从前端移除：

- `/history/summary`
- `/history/growth`
- `/history/reports`
- 历史删除接口
- `/jobs/search`
- `/analysis/match`
- `/analysis/path`
- `/analysis/growth-plan`
- `/user/login`
- `/user/register`
- `/user/profile`

## 3. 修复的问题

### 学生画像回填

- 统一从真实 `data.profile` 读取字段，不再从响应顶层错误读取 `skills/certificates`。
- 集中适配 `education/major/skills/certificates/projects/internships/workExperience/targetJob`。
- 支持从嵌套 `education` 对象或数组提取专业。
- 数据输入页会展示真实解析结果；后端没返回的字段明确显示“后端未返回”。
- 当前后端明确要求 LLM 返回的是 `name/skills/certificates/education/internships/projects`。工作经历和目标岗位不是当前响应 Schema 的保证字段，前端仅在后端真实返回时展示，不补默认值。

### 历史假接口

- 删除所有不存在的历史汇总、成长和报告列表调用。
- 历史列表改用 `/users/{userId}/histories`。
- 详情改用 `/histories/{id}/snapshot`，并展示快照中的真实报告内容。
- 删除操作已从 UI 和 Store 中移除，因为后端没有删除能力。
- 成长曲线由真实历史匹配分按日期生成；没有分数时不生成曲线点。

### 人岗匹配假分数

- 删除雷达图固定 `65/80`。
- 缺少完整维度时显示“暂无雷达数据”，不绘制伪维度。
- 总分缺失会被视为契约错误，不再自动转换成 0 分。
- 图谱岗位不再自动获得目标岗位 100 分等合成分数。

### Skill Gap 假优先级

- 使用后端 `gap_analysis` 的真实顺序、状态、建议和可选优先级。
- 后端当前未返回优先级时显示“待评估”。
- 删除“紧急/重要/一般”循环分配逻辑。

### 岗位 Mock fallback

- 删除正式岗位页的三条演示岗位。
- 加载中显示 loading。
- 成功但无结果显示真实空状态。
- 请求失败显示安全错误提示和重试操作。
- 不再尝试不存在的 `/jobs/search`。
- 未新增 `VITE_DEMO_MODE`，因为项目当前没有既有 Demo 开关；正式运行时已完全取消自动演示数据回退。

### 成长计划默认模板

- 删除无报告时的默认成长模板。
- 有完整上下文时调用真实 `/reports/generate`，再读取 `/reports/{id}`。
- 没有画像/匹配上下文时显示引导空状态。
- 报告生成但无正文时明确提示后端未返回内容。
- 学习资源继续使用真实 `/recommendations`。
- “内容检查”没有对应后端接口，当前只提示功能尚未提供，不再错误复用推荐接口。

### Profile 模拟数据

- 删除示例邮箱、Premium、固定会员信息和静态成长曲线。
- 仅显示当前 Store 中实际存在的用户标识、名称和角色。
- 历史数据只在真实接口成功后展示；接口失败时不会显示本地缓存冒充最新结果。
- 报告分数允许为空，空值显示“暂无”。

### 首页营销数字

- 删除 `98.5%`、`500强`、`+45%`、`24h` 及无法验证的用户规模数字。
- 保留公开 Landing Page 布局，改成不带运营数字的能力描述。
- 没有将首页改造成 Dashboard。

### AI 助手假实现状态

- 删除岗位库中的前端正则/规则回复。
- 保留抽屉组件作为下一阶段入口占位。
- 当前明确显示“百宝箱 Agent 接入准备中”，不会让用户误认为是真实 AI。
- 未新增前端 LLM 调用，也未接入百宝箱。
