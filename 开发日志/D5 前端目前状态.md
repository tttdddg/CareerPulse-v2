## Mock 与真实 FastAPI

已静态确认接入真实 FastAPI 的链路：

- 数据输入：`/student/upload/resume`、`/student/upload/profile`
- 岗位：`/jobs`、`/jobs/{id}/profile`、`/jobs/{id}/graph`
- 匹配：`/matching/analyze`
- 报告与学习建议：`/reports/generate`、查询、润色、导出、`/recommendations`
- 历史：`/users/{userId}/histories`、`/histories/{id}/snapshot`

对应前端请求集中在 [career.ts](D:\\vue\\CareerPulse-Pro\\front\\src\\api\\modules\\career.ts)，后端路由在 [backend routes](D:\\vue\\CareerPulse-Pro\\backend\\app\\routes\\jobs.py)。

仍在使用 Mock 或前端兜底的部分：

- `mockApi.ts` 已经没有任何页面导入，属于遗留死代码。
- 登录仍固定为 `admin / 123456`，验证码也是浏览器内随机生成；未接后端认证。[Login.vue](D:\\vue\\CareerPulse-Pro\\front\\src\\views\\login\\Login.vue)
- 岗位库请求为空或失败后展示 3 条硬编码“演示岗位”。
- AI 助手完全是前端规则回复。
- 匹配页含硬编码岗位画像预设；API 数据不完整时雷达图会生成固定的 65/80 分占位值。[career.ts](D:\\vue\\CareerPulse-Pro\\front\\src\\api\\modules\\career.ts)
- 成长计划在没有报告时加载默认模板。
- 个人中心使用 `example.com` 邮箱、`Premium` 等模拟信息，并在无数据时展示固定成长曲线。
- 首页的“98.5%、500 强、+45%、24h”等均为静态营销数字。

还发现两处接口契约风险：

1. 学生上传后端将画像放在 `data.profile`，前端主要从顶层读取 `skills/certificates`，因此真实请求成功后表单字段仍可能无法回填。
2. 历史页调用的 `/history/summary`、`/history/growth`、报告详情/删除等接口在当前 FastAPI 路由中不存在；只有历史列表和快照是真实匹配接口。

百宝箱方面，后端虽然有平台 HTTP 工具和可选 MCP Server，但 Vue 没有调用；`.env.example` 中 MCP 默认也是关闭状态，因此当前不能认定已经完成百宝箱 WebSDK/API 联调。

## 移动端响应式判断

当前属于“有基础响应式，但尚不具备可验收的完整移动端能力”。

已有基础：

- 有 viewport 配置。
- 主要页面存在 720～1200px 断点，表单、分析、路径、计划和历史页会降为单列。
- ECharts 和路径图组件监听窗口或容器尺寸变化。

主要不足：

- 900px 以下只是把侧边栏堆到页面顶部，没有移动端抽屉、汉堡菜单或底部导航。
- 移动端仍保留较大的主内容边距。
- 岗位卡片最小宽度为 280px，在 320px 设备叠加页面边距后存在横向溢出风险。
- 历史详情弹窗固定为 560px。
- 成长计划和个人中心只有平板级断点，没有针对 320～480px 的按钮、弹窗、编辑器专项处理。
- 尚未发现 320/768 等视口的自动化或截图验收测试。
