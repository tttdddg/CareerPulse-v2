本轮全站响应式适配已完成。PC 视觉保持不变，手机端使用同一套 Vue 页面自适应，没有新增第二套前端或修改业务接口。

## 1. 响应式策略

采用统一断点：

- Desktop：`>= 1200px`
- Tablet / Small Desktop：`768–1199px`
- Mobile：`< 768px`
- Small Mobile：`<= 480px`
- Extreme Small：仅在 `320px` 必要位置处理

处理原则：

- PC 保留原 Sidebar、Header、卡片尺寸和双栏结构。
- Tablet 缩小主内容间距，卡片调整为两列或单列。
- Mobile 使用 Drawer 导航，页面主体单列，按钮和表单允许换行或占满宽度。
- 未修改主题色、字体体系、圆角、阴影和 Element Plus 组件语言。
- 设计审查仅用于识别响应式风险，没有引入新的视觉体系。

## 2. Layout 改动

- 768px 以上继续保留原 240px Sidebar 和 74px Header。
- 768px 以下隐藏固定 Sidebar，增加 Hamburger + Element Plus Drawer。
- Drawer 与桌面 Sidebar 共用同一份导航数据。
- 当前路由高亮、职业路径禁用状态保持一致。
- 点击移动导航后 Drawer 自动关闭。
- Tablet 主内容 padding 调整为 `22px 20px`。
- Mobile 主内容 padding 调整为 `16px 12px 24px`。
- 修复全局 `box-sizing` 选择器缺少逗号的问题，解决表单真实宽度越界源。

## 4. 图表与路径图

- RadarChart：改为 `ResizeObserver`，窄屏缩小半径、轴标签和图例字号。
- GrowthChart：改为 `ResizeObserver`，手机减少 Grid padding，日期标签自动避让和旋转。
- Analysis ECharts：Gauge、WordCloud 监听页面容器尺寸；手机缩小仪表盘数字和词云字号范围。
- PathGraph：保留 X6 原交互，窄容器使用 `zoomToFit`，resize 后重新居中或适配。
- 图表容器均保持 `width: 100%`。

本地后端未启动，因此 PathGraph 浏览器验收展示的是真实 error/empty 状态；没有注入假图谱到页面结果。

## 5. Dialog / Drawer

- 成长档案历史详情 Dialog：手机宽度统一为 `calc(100vw - 24px)`，正文限制高度并滚动。
