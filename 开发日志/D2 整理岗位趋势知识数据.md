- 删除控制字符

- 缺少岗位名称、类别或行业时跳过
- 技能必须存在于标准能力标签体系
- `required_level` 必须为 `1–5`
- weight 必须为有效有限正数且不超过 `1`
- importance 不得为空
- 根据来源、岗位、行业、技能和正文生成稳定记录 ID

- 输出按岗位类别、行业、技能和记录 ID 稳定排序
